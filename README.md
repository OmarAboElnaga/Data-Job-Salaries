# Data-Job-Salaries
## 🏡 Project Overview
This Power BI dashboard presents an in-depth analysis of salary trends across various data-related job roles, work types, and company sizes. It provides insights into average salaries by employment type, work mode (hybrid, remote, on-site), experience level, and job title. The dashboard enables stakeholders to explore compensation patterns, assess job market dynamics, and make informed career or hiring decisions in the data industry.
